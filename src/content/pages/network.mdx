# THE MESH

## Mountains change everything.

Graham County is not a flat RF lab.

The network will be shaped by ridgelines, valleys, trees, elevation, antenna height, and where people actually live and travel. That's not a problem — **that's the interesting part.**

## The network model

### CLIENT

Personal nodes carried by people.

### ROUTER

A node intentionally positioned to extend and move traffic through the network.

### REPEATER

A strategically placed infrastructure node designed to improve coverage.

### SOLAR

A self-powered outdoor node that can stay online without grid power.

## Coverage is a community project.

If you have a good hilltop, tower, barn, cabin, business, or other elevated location, you may have something the network needs: **height**.

A useful node doesn't have to be the most expensive node.

It needs:

1. A good location.
2. A good antenna.
3. A sensible configuration.
4. Reliable power.
5. Someone willing to keep an eye on it.

## Mapping the network

As nodes come online, this page will become the home for:

- Active node locations
- Repeater locations
- Coverage tests
- Known dead zones
- Field-test reports
- Suggested deployment locations

For privacy and safety, exact private node locations won't automatically be published.

## Want to host a node?

Hosting infrastructure is one of the most valuable ways to help.

A good host provides a location and power. The mesh community can help with hardware, configuration, antenna placement, and testing.
